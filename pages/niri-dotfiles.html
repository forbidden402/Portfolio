01

Workstation Philosophy & Tooling

Rather than relying on resource-heavy desktop environments, this setup pairs Fedora with niri—an infinite horizontal scrollable-tiling Wayland compositor—and Ghostty for high-throughput GPU-accelerated terminal emulation. The result is zero desktop bloat with instantaneous workspace navigation between SIEM dashboards, packet capture consoles, and code editors.

02

Network & DNS Hardening

  • DNS-over-TLS (DoT): Configured native systemd-resolved with Quad9 (9.9.9.9#dns.quad9.net) as primary strict encrypted DNS provider, preventing local ISP tampering or passive metadata collection.
  • WireGuard MTU Tuning: Created custom NetworkManager dispatcher scripts enforcing MTU 1400 and a 25-second persistent keepalive on the proton0 tunnel interface to eliminate fragmentation and silent drops.
