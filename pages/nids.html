Network Intrusion Detection System (NIDS)

A self-hosted, lightweight network intrusion detection system featuring multi-layer deep packet inspection, real-time SOC alerting, automated IP forensic profiling, and OSINT threat lookups. Built to monitor a home-lab segment the way a Tier-1 SOC analyst watches live sensor telemetry.

01

Multi-Layer Detection Engine

The detection pipeline is organized hierarchically through the network stack:

  • L2–L3 Frame Capture: Asynchronous packet sniffing powered by Scapy, binding to network interfaces with optional promiscuous mode for raw frame capture.
  • L4 Transport Dissection: Deep parsing of TCP, UDP, and ICMP headers. Detects stealth port scans (SYN/FIN/XMAS), abnormal flag combinations, and sensitive port sweeps.
  • L7 Deep Packet Inspection (DPI): Extracts application layer payloads: DNS query names, HTTP methods/URIs/User-Agents, and suspicious ICMP payload data.
02

Forensic Entity Profiles & SOC Dashboard

Every internal and external IP address communicating on the wire is assigned a dedicated forensic entity profile. The system aggregates packet volume, conversation pairs, geolocation coordinates, ISP ownership, and AbuseIPDB reputation scores to compute an immediate threat score.

Technical Design & Scope

The engine is specifically optimized for home-lab and small subnet monitoring. Encrypted TLS traffic is analyzed through metadata (SNI, certificates, traffic flow patterns) without requiring invasive SSL interception.
