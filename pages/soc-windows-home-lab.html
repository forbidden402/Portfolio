Lab Architecture & Objectives

The objective of this hands-on lab was to build a complete blue-team detection and incident response pipeline within an isolated VMware virtual environment. By executing an attack end-to-end, I mapped adversary tactics directly to Windows endpoint telemetry and centralized SIEM searches.

Lab Topology & Network Configuration

All virtual machines were configured on a dedicated host-only subnet (192.168.133.0/24). The Windows 10 target forwards all operational Sysmon events via Splunk Universal Forwarder to Splunk Enterprise running on the host machine.

04 DETECT · SPLUNK SIEM

Threat Hunting in Splunk Enterprise

Moving into Splunk Enterprise, I correlated the raw Sysmon events into a unified incident timeline. Instead of looking at disconnected alerts, I built SPL queries to validate the entire attack chain.

Splunk Threat Hunting Query — Process Lifecycle & Network Correlation
index=main host=DESKTOP-BP3ESIC sourcetype="WinEventLog:Microsoft-Windows-Sysmon/Operational" (Image="*stageless.exe*" OR ParentImage="*stageless.exe*") | table _time, EventCode, Image, ParentImage, CommandLine, User | sort _time

Search Results: The query extracted 15 correlated events across the session, proving the complete sequence: binary drop → network beacon → file drop → command shell spawn → containment.

Detection Engineering — Production Alert Rule (Dropper & Beacon Correlation)
index=main sourcetype="WinEventLog:Microsoft-Windows-Sysmon/Operational" (EventCode=1 ParentImage="*\\explorer.exe" Image="*\\Downloads\\*.exe") OR (EventCode=3 DestinationPort IN (4444,4443,8080)) OR (EventCode=11 TargetFilename="*mimikatz*") | stats values(EventCode) as event_codes, values(Image) as images by ProcessGuid, User | where mvcount(event_codes) > 1

Detection & Response Recommendations

Based on the activity observed, I compiled several practical detection and response ideas focusing on network connections, suspicious file creation, and credential hygiene.

  • Network Controls: Block or alert on outbound connections to port 4444 (classic Metasploit default) from workstation subnets.
  • Behavioral Alerting: Alert on any process executing from \Downloads\ that subsequently writes an executable to C:\Users\Public\ (Sysmon Event ID 11) — a strong indicator of secondary dropper activity.
  • Endpoint Blocking: Deploy Application Allow-listing or Attack Surface Reduction (ASR) rules to block execution of unsigned binaries launched directly from Downloads with Zone.Identifier = 3 (Internet zone).
  • Threat Intel: Add the payload's MD5 and SHA-256 hashes to EDR and AV blocklists.
  • Credential Hygiene: Ensure WDigest is disabled, enable Credential Guard, and mandate a password rotation for the compromised local account.
