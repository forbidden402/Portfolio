ThreatScan v2.1.1 — Current Build

ThreatScan is a privacy-first Threat Intelligence Platform built for SOC analysts and incident responders. v2.1.1 is the current stable release — a fully modular, async FastAPI backend that correlates multi-source threat telemetry across URLs, IP addresses, domains, and files under a single interface, with zero server-side key storage and a 10-minute Redis/in-memory result cache.

The engine computes a composite risk score (0–100) weighted across all sources: AbuseIPDB abuse percentage, VirusTotal malicious vendor count, IPsum level-3 listing (+30 pts), GreyNoise malicious classification (+20), CT log velocity (capped at +20), SSL expiry/self-signed flags, Shodan CVE count, and SSL Labs grade (C or below). Risk levels: clean · low · suspicious · high · critical.

// IP · DOMAIN · DNS ANALYZER

Unified infrastructure analyzer accepting bare IPs or domains. Runs full DNS resolution (A, AAAA, MX, NS, TXT, CNAME, SOA records), DNSSEC validation, RDAP/WHOIS registration lookup, CDN fingerprinting via MurmurHash3 favicon hashing, and an SSL Labs deep TLS audit grading A–F with individual CVE checks: Heartbleed, POODLE, BEAST, FREAK, DROWN, ROBOT, Logjam, Ticketbleed. Certificate Transparency velocity scoring flags domains with >10 certificates issued in 30 days as potential fast-flux or phishing kit infrastructure. The same full threat feed stack as the URL analyzer runs in parallel across all resolved IPs.

// FILE & HASH ANALYZER

  • File Upload: Reads the raw binary, computes MD5, SHA-1, and SHA-256 hashes locally. Runs local YARA matching against compiled rule files — gracefully disabled if the YARA engine is unavailable at runtime. Automatically forwards the SHA-256 to the hash cloud lookup pipeline.
  • Hash Lookup: Cross-references the submitted hash against MalwareBazaar and ThreatFox (both abuse.ch). A single shared abuse.ch Auth-Key covers both services as a fallback. Returns malware family, tags, file type, and first-seen metadata.

// REPORTS ENGINE

Generates a unique per-investigation report ID for every scan and exports structured PDF (ReportLab) and DOCX (python-docx) reports containing: composite threat score, risk reason table (source → finding → weight → severity), DNS records, IP intelligence, port inventory (live + passive), TLS summary, RDAP registration, subdomain list, and full provider status matrix.

// CACHING & PRIVACY MODEL

  • Redis-first with in-memory fallback: Scan results are cached for 10 minutes. On Redis failure the app silently falls back to a process-level in-memory store — no crash, no degraded UX. Cache entries are session-scoped so different analysts' results never collide.
  • Zero server-side key storage: All third-party API keys (VirusTotal, AbuseIPDB, Shodan, OTX, IPQS, etc.) live exclusively in the analyst's browser local storage. They travel per-request as encrypted request headers and are never written to server disk or stored in the cache.

Roadmap · v3.5 — Next Release

v3.5 is currently in active development and will expand ThreatScan into a full-spectrum static malware analysis and email forensics platform. The following features are planned for this major release:

Feature Category Description
PE Shannon Entropy Static Analysis Section-level entropy scoring on PE binaries — detects packed, encrypted, or polymorphic payloads without execution. Sections above threshold (≥ 7.0) are flagged with severity level and included in report export.
Archive Sandboxing File Analysis Automatic extraction and inspection of password-protected ZIP, RAR, and 7z archives using configurable wordlists — a delivery vector commonly bypassed by AV solutions.
Email Threat Analyzer Email Forensics Full email file parsing: SPF, DKIM, DMARC header validation; sender IP reputation via AbuseIPDB; embedded URL detonation against URLhaus and VirusTotal; attachment hash scanning with malware verdict.
YARA Engine Static Analysis Analyst-supplied YARA rule sets applied against uploaded binaries and extracted archive contents. Match results (rule name, strings, offsets) exported to the forensic report.
v3.5 Report Schema Reporting Enhanced PDF and DOCX export templates with entropy charts, YARA match tables, email forensic summaries, and multi-engine IOC verdicts in a single artefact.
