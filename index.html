WHAT IT DOES

ThreatScan is a unified TIP for SOC analysts and incident responders. It runs four analysis engines from one dashboard: a URL Analyzer for phishing/malicious link triage, an Infrastructure Analyzer for IP/DNS/domain perimeter checks, a File & Hash Analyzer for uploads up to 32MB or hash lookups, and a Reports module that consolidates every scan into exportable PDF/DOCX records.

HOW I BUILT IT

Backend is FastAPI split into engine-specific routers: file_analyzer/, ip_dns_domain_analyzer/, url_analyzer/, plus shared core/, auth/, threat_feeds/ and reports/ modules. Frontend is dependency-free plain HTML/CSS/JS calling the FastAPI backend directly.

PRIVACY / SECURITY MODEL

Built zero-trust and ephemeral: sessions, cached scan data and temp files are wiped 24 hours after creation. Third-party API keys live only in the browser's local storage — never written to server disk.

Network Intrusion Detection System
A real-time, self-hosted NIDS with deep packet inspection, a live SOC dashboard, entity/IP forensic profiles, and OSINT-backed threat lookups — built to watch a home network the way a Tier-1 analyst watches a SIEM.

WHAT IT DOES

Monitors a live network segment and flags suspicious activity in real time. Ships with a live telemetry dashboard, network topology map, per-IP forensic entity profiles, threat-intel IP lookup, and CSV export for SIEM ingestion.

THE DETECTION ENGINE

  • Capture (L2–L3): raw frames via Scapy with optional promiscuous mode.
  • Dissection (L4): TCP/UDP/ICMP headers parsed for port-based anomalies — stealth scans and sensitive-port access flagged here.
  • Inspection (L7): application payload opened to extract DNS queries, HTTP URIs, ICMP content — real DPI, not just header stats.
  • Every IP gets its own entity profile: geolocation, ISP, abuse score, risk level, and full telemetry history.

LIMITATIONS

Can't inspect TLS payloads without SSL-stripping, needs root for raw sockets, throughput bound by host CPU — scoped to LAN / home-lab monitoring.
